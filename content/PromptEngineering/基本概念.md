# 基本概念

## 给LLM提示:

结果质量与Prompt中的信息数量和完善程度有关

设计有效的提示词以指导模型执行期望任务的方法被称为**提示工程**

## 提示词格式

QA格式

```
Q: <问题>?
A: 
```

#### 零样本提示:

直接提示模型提供一个回答,而没有提供任何你希望它完成的任务的示例或者示范
示例

```
What is prompt engineering?
```

#### 少样本提示:

提供少样本示例

小样本可以赋能上下文学习能力
