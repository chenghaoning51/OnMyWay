# 12.虚拟环境和包

## 12.1概述

使用不存在标准库的软件包和模块
需要特定的库

解决方法1：创建一个虚拟环境（virtual environment):一个目录树，安装有特定版本的Python版本，以及许多其他包

## 12.2.创建虚拟环境

用于创建虚拟环境的模块：venv
例如：python -m venv tutorial-env
虚拟环境的常见目录为.venv，通常会被隐藏
激活该虚拟环境的语句：tutorial-env\Scripts\activate
撤销激活一个虚拟环境
激活的虚拟环境并不会以任何方式改变PYTHONPATH；最佳实践实在bash中执行unset PYTHONPATH

## 12.3.使用pip管理包

作用：安装升级，移除软件包
默认情况下pip或从Python Package Index安装软件包
完整的用法请查阅
